# TempMail Frontend Instructions

Read and follow `AGENTS.md` before changing this project.

Key constraints:

- This is a Svelte 4 production frontend; do not upgrade frameworks during unrelated work.
- Preserve all API behavior and the Shadow DOM email renderer.
- Design mobile-first for 360–390 px screens with readable addresses and touch-safe controls.
- Keep technical file content in English.
- Verify changes with `npm run build`.
- Do not deploy, restart services, modify Caddy, or copy build output unless explicitly requested.
